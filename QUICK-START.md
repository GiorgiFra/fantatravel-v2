# 🚀 Quick Start - Deploy in 3 Step

## 📦 **Step 1: Git Push**

```bash
cd C:\Users\france4\fantatravel-master\fantatravel-master
git add .
git commit -m "✨ UI Upgrade 2.0"
git push origin main
```

---

## 🌐 **Step 2: Attiva GitHub Pages**

1. Vai su **github.com** → tuo repo
2. **Settings** → **Pages**
3. Source: `main` branch → `/root`
4. **Save**
5. Aspetta 2 minuti

---

## 🔗 **Step 3: Ottieni il Link**

Il tuo link sarà:
```
https://[username].github.io/[repo]/preview-mobile-optimized.html
```

**FATTO!** Condividi il link! ✅

---

## 📱 **Alternativa Veloce: Netlify Drop**

1. Vai: **https://app.netlify.com/drop**
2. Trascina: `preview-mobile-optimized.html`
3. Copia link
4. **FATTO in 30 secondi!** ⚡
